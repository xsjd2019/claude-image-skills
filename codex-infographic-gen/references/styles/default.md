# default — 明るい資料調

議事録・検討まとめ・仕様整理などをそのまま配れる、明るく落ち着いた資料の質感。

**配色・装飾・イラストの具体的な設計は指定しない。** 内容に合わせて最も読みやすくなるよう、あなた（画像生成モデル）が判断すること。以下だけ守る。

## 必須

- 背景は白またはごく淡い無彩色。紙面全体が明るいこと。**不透明に塗り、透過を残さない**
- 和文フォントはサンセリフ（Noto Sans JP / 游ゴシック相当）。**明朝は使わない**
- タイトルは太字で紙面上部に置く。ただし紙面を支配するほど大きくしない
- 本文は読み手が無理なく追える字送り・行間にする
- 色は使う。ただし下の「色のルール」に従う

## 色のルール — 色数はセクション数に依存させない

**1. 使う色の役割を4つに分ける**

| 役割 | 色 | 使う場所 |
|---|---|---|
| アクセント | はっきりした彩度のある1色 | 番号バッジ、見出し脇の装飾、重要な事実値（日付・金額・人数） |
| カテゴリ色 | 淡い2〜4色 | **セクション内部で並列する要素**の区別（フロー1/2/3、案A/B/C など） |
| 意味色 | 緑・赤・黄〜橙 | 肯定／否定／注意 |
| 無彩色 | 白・淡いグレー・濃いグレー | 背景、カード、罫線、本文 |

この4役以外に色を増やさない。セクションが5個でも10個でも、色数は変わらない。

**紙面全体がグレー一色になってはいけない。** アクセント色は必ず使い、紙面に生気を持たせる。

**2. セクションごとに色を変えない**

セクションが増えるたびに色が増えると、紙面が散らかって読みづらくなる。

- **番号バッジは全セクションで同じアクセント色**。セクションごとに変えない
- **セクション見出しの文字は黒に近い色**にする。見出しまで色を付けない（色が付くのは番号バッジだけ）
- セクションの地色でセクションを区別しない

**カテゴリ色はセクションの識別には使わない。** 使うのは「セクションの中に並ぶ、優劣のない複数の要素」を見分けるときだけ（例: 3つの処理フロー、2つの導入方式）。

**3. 区画の識別は、色ではなく構造でやる**

通し番号・罫線・地色の面・余白で区切る。「色が違うから別のセクション」ではなく「番号と枠が違うから別のセクション」と読める状態にする。

**4. 彩度の高い色は、意味のある要素にだけ使う**

| 意味 | 色 |
|---|---|
| 肯定・成功・変更後・できること | 緑 |
| 否定・失敗・変更前・できないこと | 赤（対比だけならグレーでもよい） |
| 注意・気をつけること | 黄〜橙 |
| 上記に当てはまらない中立の情報 | 無彩色。色を付けない |

**5. 同じ意味には、紙面のどこでも同じ色を使う**

ある箇所で「緑＝うまくいった」としたら、別の箇所でも緑は同じ意味で使う。意味の違う要素に同じ色を使わない。

## レイアウト — カードで区切る

- ページ全体の背景は**ごく淡いグレー**にする
- 各セクションを**白いカード**（角丸・細い枠線）として置き、その中に見出し・本文・図を収める
- 罫線だけで区切るより、カードの方がセクションのまとまりが一目で分かる
- カードの中でさらに並列要素を区切るときは、カテゴリ色の淡い面を使う
- アイコンは多めに使ってよい。色はアクセント色と無彩色で統一する

※ マージンや余白の具体的な数値は、プロンプト側の「守ってほしい制約」に従う

## 方向性

- 落ち着いた資料調。カラフルだが、賑やかにはしない
- テキストだけにならず、図・表・アイコンで視覚的な変化をつける
- 読み手が上から順に淡々と追える質感
- グレーだけで構成された、沈んだ紙面にはしない
